# Security policy

## Supported versions

Security fixes are applied to the latest release on the default branch. Older
development snapshots are not supported.

## Reporting a vulnerability

Please use this repository's **Security → Report a vulnerability** flow to
submit a private report. Do not open a public issue containing credentials,
exploit details, customer data, or an unpatched vulnerability.

Include the affected component and version, reproduction steps, impact, and
any suggested mitigation. The maintainers will acknowledge the report and
coordinate remediation and disclosure through the private advisory.
