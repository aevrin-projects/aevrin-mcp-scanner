---
title: Installing an MCP server
description: What Aevrin does and deliberately does not do when you install an MCP server.
---

## Aevrin prepares; you apply

Install applies to MCP servers. Other registry items show what you need to use them directly: a
prompt to copy, instructions to follow, or a `git clone` command for a repository and its ref.

Pressing **Install** does not install anything. It shows the exact configuration your client
needs, with every warning that applies.

This is deliberate. Aevrin never writes to your machine's configuration, never runs a server's
install command, and never executes a package's postinstall hooks to find out what it does.

The registry does not scan what it lists, so nothing here tells you whether the server is safe. Scan
it first with **Scan with Aevrin** on its page (see
[Scanning a server you found](/overview#scanning-a-server-you-found)).

## What the install dialog shows

**The agent.** Only clients the server's own metadata supports are offered. If it declares no
transport Aevrin recognises, there is no install option: speaking MCP in principle is not the same
as being installable.

**Warnings**, which may include:

- A secret-valued environment variable, named so you know what to set
- No pinned version, meaning the launcher fetches whatever is current at run time
- A remote server, whose operator can change its behaviour without changing anything visible locally

**The configuration**, with secret values left blank. Aevrin has no business supplying a credential,
and a config that arrived pre-filled would be a config carrying somebody's token through a
registry.

The same configuration and warnings are on the item page under **Use it**, and are what the registry
MCP tools return to an agent.

## After installing

Apply the configuration, then run a scan of your machine so the server appears in your inventory
with its posture:

```bash
aevrin scan --agents
```

The MCP server is then correlated with the agents that use it, and any capability it grants shows up
in your permission surface.
